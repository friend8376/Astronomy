# AstroQuest — เรียนดาราศาสตร์แบบอินเทอร์แอกทีฟ

เว็บแอปสำหรับเรียนดาราศาสตร์พื้นฐานครบ 22 บท ตามโครงหัวข้อของหนังสือ *Fundamental Astronomy* (Karttunen et al., Springer) แต่ละบทมี

- **บรรยาย** — เนื้อหาเรียบเรียงใหม่เป็นภาษาไทย พร้อมสมการ (KaTeX) และแผนภาพประกอบสไตล์ตำรา
- **ห้องทดลอง / เกม** — การจำลองที่ลงมือเล่นได้ ฝังอยู่ในหัวข้อที่เกี่ยวข้อง
- **แบบทดสอบ** — ปรนัย มีเฉลยและคำอธิบาย
- **โจทย์คำนวณ** — สุ่มตัวเลขใหม่ทุกครั้ง ตรวจคำตอบฝั่งเซิร์ฟเวอร์

ทั้งโปรเจกต์อยู่ในไฟล์เดียวคือ `app.py` (Flask + Tailwind CDN)

> เนื้อหาและแผนภาพทั้งหมดเขียนและวาดขึ้นใหม่ ไม่ได้คัดลอกข้อความหรือรูปจากหนังสือต้นฉบับ ตัวเลขในแบบจำลองถูกทำให้ง่ายลงเพื่อการเรียนรู้

---

## สิ่งที่ต้องมี

- Python 3.9 ขึ้นไป
- Flask 3.x
- อินเทอร์เน็ต — หน้าเว็บโหลด Tailwind, KaTeX และฟอนต์จาก CDN

## ติดตั้งและรัน

```bash
pip install flask
```

```bash
python app.py
```

แล้วเปิดเบราว์เซอร์ไปที่ <http://127.0.0.1:5000>

บน Windows ถ้าพิมพ์ `python` แล้วขึ้นข้อความให้ติดตั้งจาก Microsoft Store ให้ใช้ `py` แทน:

```bash
py app.py
```

หยุดเซิร์ฟเวอร์ด้วย `Ctrl + C`

## วิธีใช้งาน

### หน้าแรก (แผนที่บทเรียน)
- บทเรียนแบ่งเป็น 5 ภาค แต่ละการ์ดแสดงภาพปก ชื่อบท และความคืบหน้า
- ปุ่ม **"เรียนต่อ"** พาไปยังบทแรกที่ยังอ่านไม่จบ

### หน้าบทเรียน
- **สารบัญ** อยู่ด้านซ้าย (บนมือถือพับไว้ด้านบน) แตะเพื่อเลื่อนไปยังหัวข้อนั้น
- อ่านบรรยายตามลำดับ ห้องทดลองจะแทรกอยู่หลังหัวข้อที่เกี่ยวข้อง
- ในห้องทดลองมีกล่อง **ภารกิจ** ทำสำเร็จแล้วได้ XP กด **"สุ่มภารกิจใหม่"** เพื่อเล่นซ้ำ
- บทที่ไม่มีห้องทดลอง (11, 13, 16, 17, 21) มี **เกมจับคู่แนวคิด** ท้ายบท
- ท้ายบทมี **ตารางสรุปแนวคิด**, ปุ่ม **"ทำเครื่องหมายว่าอ่านจบ"** (+20 XP) และลิงก์ไปแบบทดสอบ/โจทย์คำนวณ

### แบบทดสอบ
- สุ่มลำดับข้อทุกครั้ง ตอบแล้วเห็นเฉลยและคำอธิบายทันที
- ได้ 10 XP ต่อข้อ เฉพาะส่วนที่ทำได้เกินคะแนนสูงสุดเดิม

### โจทย์คำนวณ (เมนู "แบบฝึกหัด")
- เลือก **สุ่มทุกหัวข้อ**, **สุ่มในบทเดียว** หรือเลือกโจทย์แบบเจาะจง (มี 29 แบบ)
- พิมพ์ตัวเลขได้ทั้ง `12.5`, `4.2e9` หรือ `4.2×10^9` ยอมรับความคลาดเคลื่อนราว 2%
- ตอบได้ 2 ครั้ง: ถูกครั้งแรก +15 XP, ครั้งที่สอง +8 XP, ผิดสองครั้งจะเฉลยพร้อมวิธีทำ
- ถูกติดกันทุก 5 ข้อได้โบนัส +20 XP กด **"สูตร"** เพื่อดูคำใบ้

### XP ยศ และดาว
- XP สะสมแล้วเลื่อนยศได้ 7 ระดับ (แถบด้านบนขวา)
- แต่ละบทมีดาว 3 ดวง: อ่านจบ · ผ่านห้องทดลอง/เกม · แบบทดสอบได้ 80% ขึ้นไป
- ความคืบหน้าเก็บใน `localStorage` ของเบราว์เซอร์ (คีย์ `astroquest-v1`) จึงแยกตามเบราว์เซอร์/เครื่อง
- ล้างความคืบหน้าได้ด้วยลิงก์ **"ล้างความคืบหน้า"** ที่ท้ายหน้า

## โครงสร้างภายใน `app.py`

| ส่วน | หน้าที่ |
|---|---|
| `PARTS`, `CHAPTERS` | รายชื่อภาคและบท, ห้องทดลองของบท, แนวคิดสำคัญ (ใช้ทำตารางสรุปและเกมจับคู่) |
| `COVERS` | แผนภาพที่ใช้เป็นภาพปกของแต่ละบท |
| `md()`, `sec()`, `LECTURES` | เนื้อหาบรรยายของแต่ละบท |
| `QUIZ` | แบบทดสอบ |
| `g_*()`, `EXERCISES` | ตัวสร้างโจทย์คำนวณแบบสุ่ม |
| Routes | API (ดูด้านล่าง) |
| `PAGE` | หน้าเว็บทั้งหมด: HTML, CSS, JavaScript, แผนภาพ (`FIG`) และห้องทดลอง (`LABS`) |

### API

| Method | Path | คำอธิบาย |
|---|---|---|
| GET | `/` | หน้าเว็บ |
| GET | `/api/chapters` | รายชื่อภาคและบท |
| GET | `/api/lecture/<id>` | เนื้อหาบรรยายของบท |
| GET | `/api/quiz/<id>` | คำถามแบบทดสอบ (ไม่มีเฉลย) |
| POST | `/api/quiz/check` | ตรวจคำตอบ `{cid, qid, choice}` |
| GET | `/api/exercise?type=<key>` หรือ `?ch=<id>` | สุ่มโจทย์คำนวณ |
| POST | `/api/exercise/check` | ตรวจคำตอบ `{id, answer}` |

คำตอบของโจทย์คำนวณเก็บไว้ในหน่วยความจำของเซิร์ฟเวอร์ ถ้ารีสตาร์ตเซิร์ฟเวอร์ โจทย์ที่เปิดค้างอยู่จะขึ้นว่า "หมดอายุ" ให้กด **"โจทย์ถัดไป"**

## การแก้ไขหรือเพิ่มเนื้อหา

### เพิ่ม/แก้หัวข้อบรรยาย
แต่ละบทคือรายการของ `sec(...)`:

```python
LECTURES[7] = [
    sec("ชื่อหัวข้อภาษาไทย", "English Section Title", r"""
        ย่อหน้าแรก ใช้ **ตัวหนา** และสมการในบรรทัด \(E = mc^2\)

        - รายการที่ 1
        - รายการที่ 2

        \[ P^2 = \frac{4\pi^2}{G(m_1+m_2)}\,a^3 \]

        > กล่องหมายเหตุ
    """, figs=["ellipse"], lab=True),
]
```

- คั่นย่อหน้าด้วยบรรทัดว่าง
- บรรทัดขึ้นต้นด้วย `- ` = รายการ, `> ` = กล่องหมายเหตุ
- บล็อกที่ขึ้นต้นด้วย `\[` = สมการแบบแยกบรรทัด
- ใช้ `r"""..."""` เสมอ เพื่อไม่ให้ backslash ของ LaTeX ถูกตีความ
- `figs` คือรายการคีย์ของแผนภาพใน `FIG`
- `lab=True` วางห้องทดลองต่อจากหัวข้อนี้ (ถ้าไม่ระบุ ห้องทดลองจะอยู่ท้ายบท)

### เพิ่มข้อสอบ
```python
QUIZ[7].append(("คำถาม?", ["ตัวเลือก A", "ตัวเลือก B", "ตัวเลือก C", "ตัวเลือก D"], 1, "คำอธิบายเฉลย"))
```
ตัวเลขตัวที่สามคือดัชนีคำตอบที่ถูก (เริ่มจาก 0)

### เพิ่มโจทย์คำนวณ
เขียนฟังก์ชันที่คืนค่า `dict` แล้วลงทะเบียนใน `EXERCISES`:

```python
def g_example():
    a = round(random.uniform(1, 10), 2)
    return dict(q=f"โจทย์ที่มีค่า <b>a = {a}</b>", unit="AU", ans=a ** 2,
                hint="สูตรที่ใช้", sol=f"วิธีทำ = {a**2:.3g}")
    # เลือกใส่ rtol=0.02 (ความคลาดเคลื่อนสัมพัทธ์) หรือ atol=0.5 (สัมบูรณ์)

EXERCISES["example"] = (7, "ชื่อโจทย์", g_example)
```

### เพิ่มแผนภาพ
ใน `PAGE` ส่วน "แผนภาพประกอบ" ใช้ฟังก์ชันช่วยวาด (`ln`, `ar`, `ci`, `tx`, `pa`, `curve`, `axes`, `sphere` ฯลฯ):

```js
FIG.mykey = { cap: 'คำบรรยายใต้ภาพ', svg: () => {
  let b = axes(60, 280, 620, 20, 'แกน x', 'แกน y') + pa(curve(x => x * x, 0, 10, x => 60 + x * 50, y => 280 - y * 2.5), 'kb w');
  return svgw(640, 300, b);
} };
```

คลาสเส้น: `k` ดำ, `kr` แดง, `kb` น้ำเงิน, `ka` อำพัน, `kg` เขียว, `kq` เทา และต่อท้ายด้วย `w` (หนา), `t` (บาง), `d` (เส้นประ), `dd` (จุดไข่ปลา)

### เพิ่มห้องทดลอง
เขียน `LABS.mylab = (root, chapter) => { ... }` ใน `PAGE` แล้วตั้ง `lab="mylab"` ในบทนั้นของ `CHAPTERS` ดูตัวอย่างจากห้องทดลองที่มีอยู่ (เช่น `LABS.magnitude`) และใช้ `complete(key, xp, label)` เมื่อผู้เล่นทำภารกิจสำเร็จ

## ใช้งานจริงบนเซิร์ฟเวอร์

`app.py` รันด้วย `debug=True` ซึ่งเหมาะกับการพัฒนาเท่านั้น ถ้าจะเปิดให้คนอื่นใช้ ให้รันผ่าน WSGI server แทน เช่น

```bash
pip install waitress
```

```bash
waitress-serve --port=8000 app:app
```

(บน Linux/macOS ใช้ `gunicorn app:app` ได้เช่นกัน)

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|---|---|
| หน้าเว็บไม่มีสไตล์ / สมการเป็นข้อความ `\(...\)` | ตรวจการเชื่อมต่ออินเทอร์เน็ต (Tailwind และ KaTeX โหลดจาก CDN) |
| `Address already in use` | มีโปรแกรมใช้พอร์ต 5000 อยู่ ปิดโปรแกรมนั้น หรือแก้เป็น `app.run(debug=True, port=5001)` |
| `ModuleNotFoundError: No module named 'flask'` | รัน `pip install flask` (หรือ `py -m pip install flask` บน Windows) |
| โจทย์คำนวณขึ้นว่า "หมดอายุ" | เซิร์ฟเวอร์ถูกรีสตาร์ต กด "โจทย์ถัดไป" |
| อยากเริ่มนับ XP ใหม่ | กด "ล้างความคืบหน้า" ที่ท้ายหน้า |

ไฟล์ `.claude/launch.json` ใช้สำหรับเปิดเซิร์ฟเวอร์ภายในแอป Claude เท่านั้น ลบทิ้งได้โดยไม่กระทบการทำงาน
